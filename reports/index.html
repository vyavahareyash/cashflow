🛡️ Engineering Retrospective: Incident Post-Mortems & Crisis Management
Real-world failure modes, root-cause analyses & architectural remediations
🔒 SQLite Database File Lock Contention
Concurrency & ACID
Trigger: Concurrent test execution across multiple parallel test runner isolates in local & CI suites.
Failure: Spurious sqlite3.OperationalError: database is locked (code 5) and dirty state leakage across assertions.
Remedy: Enforced strict harness serialization (flutter test --concurrency=1), isolated ephemeral DB fixture paths, and atomic test rollbacks.
Key Engineering Takeaway Single-process SQLite embedded engines require deterministic harness constraints and architectural guards over unconstrained thread parallelization.
🧠 Non-Deterministic Local SLM Hallucination
Edge AI & Grammar
Trigger: Extracting double-entry transaction entities from freeform spoken voice input using on-device SLMs without cloud fallbacks.
Failure: Unconstrained model output generated invalid JSON tokens, hallucinated account identifiers, and broke accounting balance invariants.
Remedy: Offloaded inference to background Dart isolates and compiled strict GBNF context-free grammar constraints directly into the model token sampler.
Key Engineering Takeaway Mission-critical on-device AI cannot depend on prompt engineering alone; hard grammar decoding constraints at sampling time are essential for 100% schema integrity.
🔄 Reactive State Drift in Multi-Table Writes
State & Reactivity
Trigger: Interdependent balance updates across Safe-to-Spend calculations, goal lock reserves, and credit card debt ledger accounts.
Failure: Dashboard UI displayed stale usable balances after nested edits; polling the database caused severe 60fps frame drops.
Remedy: Engineered a lightweight, centralized revision sequence (DatabaseHelper.dataRevision) paired with targeted ListenableBuilder consumers.
Key Engineering Takeaway Decoupled atomic database mutations from reactive UI updates via a minimal monotonic revision bus, avoiding complex third-party state synchronization bloat.
🌐 Zero-Network Privacy vs Heavy Model Distribution
Privacy & Security
Trigger: Supporting offline Whisper voice transcription and local SLM inference without bloating the initial app package.
Failure: Bundling model weights blew base APK size past 150MB; automated background downloads would violate the app's zero-network privacy covenant.
Remedy: Created a 100% user-initiated on-demand model manager featuring SHA-256 cryptographic verification and strictly sandboxed local weight storage.
Key Engineering Takeaway Absolute user privacy requires verifiable cryptographic integrity checks and strict user-consent boundaries for all external weight artifacts.
